# Security Policy

## Supported Versions

We support and patch security updates for the following versions:

| Version | Supported |
|---------|-----------|
| 1.0.x   | ✅ Yes    |
| < 1.0   | ❌ No     |

## Reporting a Vulnerability

We take the security of Fresh Market seriously. If you find any vulnerability (e.g., privilege escalation, rule bypass, data manipulation issues), please do not report it publicly via GitHub issues. 

Instead, report it by emailing the security team at **security@freshmarket.com**.

Please include:
* A detailed description of the vulnerability.
* Steps to reproduce or a Proof of Concept (PoC).
* Potential impact of the vulnerability.

We will acknowledge your report within 48 hours and work with you to resolve the issue promptly before disclosure.
